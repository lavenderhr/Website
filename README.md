# Lavender HR — GitHub Pages Website

A modern static website for Lavender HR Ltd.

## Files
- `index.html` — Home
- `services.html` — Services
- `about.html` — About Me
- `contact.html` — Contact
- `privacy.html` — Privacy Policy
- `404.html` — GitHub Pages fallback
- `css/style.css` — Styling
- `js/script.js` — Navigation, scroll effects, counters and contact form
- `images/logo.jpg` — supplied Lavender HR logo
- `images/profile.png` — supplied profile image
- `images/hero.svg` — bespoke lavender botanical/people illustration

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Contact form
Because GitHub Pages is static hosting, the contact form does not submit data to a server. The JavaScript prepares an email in the visitor's default mail application addressed to `contactus@lavenderhr.co.uk`.

If you later want a server-backed form, replace the form handler with a service such as Formspree or another form provider.
